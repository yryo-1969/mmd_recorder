# MMDレック

MikuMikuDance の再生ボタンを自動で監視して、押した瞬間に録画開始・止めた瞬間に録画終了してくれる画面録画ツールです。タイミングを手動で合わせる必要がありません。

- 録画対象は「画面（3Dビュー）だけ」か「MMD全体（パネル込み）」を選択できます。
- 画質は MP4（軽量・すぐ共有向け）と AVI（UtVideo無劣化・AviUtl編集素材向け）の2モード。
- システム音声（MMDの再生音）も一緒に録音できます。
- 4K解像度の録画・変換にも対応しています（解像度に応じてビットレートを自動調整するので、フル画面録画がMMDの実解像度のまま高精細に残せます）。
- 高画質(AVI)モードで録画したファイルは、そのまま軽量なMP4への変換も内蔵しています。変換中は進行状況（%）が表示されます。変換だけしたい場合は、AVIファイルを本体にドラッグ＆ドロップするだけです。

Windows専用（MikuMikuDance本体がWindows専用のため）。

## ダウンロード（Pythonなしで使う）

[Releases](../../releases) から `MMDレック.zip` をダウンロードして展開し、MikuMikuDance を起動した状態で `MMDレック.bat` をダブルクリックするだけで使えます。インストール作業は不要です。

## 使い方

1. `app` フォルダと `MMDレック.bat` は、同じフォルダの中にまとめて置いたままにしてください（バラバラにすると動きません）。
2. **録画したいとき**: MikuMikuDance を起動した状態で `MMDレック.bat` をダブルクリック。質問（画面のみか／画質モード／音声ありか）に答えたあと、MMD側の再生ボタンを押すと自動で録画が始まり、止めると自動で録画が終わります。
3. **AVIをMP4に変換したいとき**: 高画質(AVI)モードで撮ったファイルを `MMDレック.bat` にドラッグ＆ドロップするだけで、MP4に変換できます（音声を含めるかも選べます）。

## 知っておくと安心なこと

- 高画質(AVI)モードはファイルサイズがかなり大きくなります（AviUtlなどでの編集素材用途を想定しています）。
- 変換にはファイルサイズによって5分以上かかることがあります。進行状況（%）が進んでいれば正常に動作中です。
- 「画面のみ」録画時は、MMDのウィンドウサイズが一時的に調整されます（録画用の固定サイズに合わせるためです）。

## 使用ライブラリについて

MMDの再生状態の検出には、ビームマンP様が開発・公開されている [mmd-mcp](https://github.com/BeamManP/mmd-mcp) を利用しています（MIT No Attributionライセンス）。
